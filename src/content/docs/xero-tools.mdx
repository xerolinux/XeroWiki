## Customization Hub

The **XeroLinux Customization Hub** is a PyQt6-based GUI tool that brings together all XeroLinux themes, rices, scripts, and system tools in one interface. It works on **any Arch-based system**, not just XeroLinux.

<Image src={xeroTool} alt="XeroLinux Customization Hub" />

### Features

- **Desktop Rices**: Pre-configured desktop themes and layouts
- **GRUB Themes**: 8 bootloader themes
- **Scripts & Tools**: System utilities and configuration scripts

---

### Execution

- **Dependencies**

```bash
sudo pacman -S python python-pyqt6
```

- **Run The Tool**

```bash
curl -fsSL https://xerolinux.xyz/script/xero-tool.py | python3
```

## Fingerprint GUI

**XeroLinux Fingerprint GUI** (`xfprintd-gui`) is a GTK4 fingerprint manager built in Rust. It provides a clean interface for enrolling and managing fingerprints and configuring where fingerprint authentication is accepted on your system.

<div class="img-row">
  <Image src={xfprintdMain} alt="Fingerprint GUI main window" />
  <Image src={xfprintdList} alt="Enrolled fingerprint list" />
</div>

### Features

- Enroll new fingerprints with live scan feedback and retry guidance
- Remove existing fingerprints with confirmation
- Configure fingerprint auth for the login screen, terminal, and sudo
- View all enrolled fingerprints in one list

:::note[Requirements]
Requires a connected fingerprint reader and the `fprintd` service running (usually automatic). Designed specifically for XeroLinux.
:::

### Install

```bash
sudo pacman -S xfprintd-gui
```

## Howdy-Qt

:::caution
**Howdy** the back-end tool was abandoned ages ago back in 2020. What we are doing here, with the GUI, is an attempt at potentially bringing it back from the ashes. Project uses **Howdy-git** for latest commits. That, however doesn't mean that it's suddenly up-to-date. This relies on original dev. We tested it and seems to work with a few bugs here n there. Nothing we can do about that.
:::

This tool is for the few of you using **Linux/XeroLinux** on a [**Windows Hello**](https://learn.microsoft.com/en-us/windows-hardware/design/device-experiences/windows-hello-face-authentication) supported device or Laptop. It's a G.U.I front-end for a C.L.I tool called [**Howdy**](https://github.com/boltgolt/howdy). I worked hard on it, and it was improved upon by [**Marco-M**](https://github.com/morettimarco) a contributor to the project.

<Image src={howdyQt} alt="XeroLinux Howdy-Qt" />

### Features

  - Test face recognition
  - SDDM/PLM Support (KDE)
  - Manage face models (add/remove)
  - Enable/disable Howdy globally
  - Select & preview camera device
  - Toggle face auth per service (sudo, login, polkit, etc.)

### Installation

Any Arch-based Distro. You need to subscribe to repo on [**Github**](https://github.com/xerolinux/xero-howdy-qt) follow it for updates.

```bash
git clone https://github.com/xerolinux/xero-howdy-qt
cd xero-howdy-qt/Packaging/ && makepkg -si
```

> For **SDDM/PLM**, hit enter on empty password field first, same goes for the Lock Screen. Then it'll work.

To see features, test it out, follow progress and report any issues or suggestions visit the the tool's [**Github Repo**](https://github.com/XeroLinux/xero-howdy-qt).

## Wallpaper Browser

<Image src={wallsGuiDemo} alt="Xero Wallpapers demo" />

Find, preview and set wallpapers and live wallpapers from multiple online sources, all from one app. Built with PyQt6, QML and Kirigami.

### Sources

**Static:** 4K Wallpapers, HDQWalls, WallpaperCave, Wallhaven

**Live/Video:** DesktopHut, LiveWallpapers4Free, Lively, MoeWalls, MotionBGs

### Features

  - Filter by tags, colour, resolution, and aspect ratio
  - On-device AI "No Anime" filter (CLIP model - nothing uploaded)
  - Fullscreen coverflow browsing
  - Crop and upscale images before saving
  - Local wallpaper library with tabbed viewer
  - Batch download with progress tracking
  - Set static wallpapers directly (auto-detects your DE)
  - Plasma slideshow plugin + live wallpapers via Smart Video Wallpaper Reborn
  - Supported DEs: Plasma, GNOME, XFCE, Cinnamon, Hyprland, Niri

### Installation

**XeroLinux:**

```bash
sudo pacman -S xero-wallpaper-browser
```

**Other distros:** Download the AppImage from [**GitHub Releases**](https://github.com/xerolinux/xero-wallpapers-gui/releases). It self-updates when a new version is available.

:::note
Live wallpapers, the Plasma slideshow plugin, and Smart Video Wallpaper Reborn require KDE Plasma.
:::

## Speed Test GUI

**xSpeedTest** is a Qt6/QML speed test for KDE Plasma. It measures download, upload, ping, and jitter with a live animated stream, follows the system theme with KWin blur, and ships a Plasma 6 widget for the desktop and panel.

<Image src={xspeedtestApp} alt="xSpeedTest in action" />

### Features

- Live animation reacting to real throughput during the test
- 35 visual styles - dark, full-width designs with one palette each
- Native KDE look: Kirigami, Qt style, Kvantum, adjustable window opacity
- Plasma 6 widget - install and update from inside the app
- Test history (last 50 results), configurable speed units, server selection

### Install

```bash
sudo pacman -S xspeedtest
```

## Troubleshooting

### Plymouth Boot Delay

On fast NVMe systems, the boot animation may flash too quickly. Add a delay:

```bash
sudo systemctl edit plymouth-quit.service --drop-in=long_splash.conf
```

Add this content:

```ini
[Service]
ExecStartPre=/usr/bin/sleep 6
```

<Image src={plymouthDelay} alt="Plymouth Delay Config" />

Adjust the `6` (seconds) to suit your hardware. Apply with:

```bash
sudo systemctl daemon-reload
```

### Plymouth Multi-Monitor

If the animation doesn't scale correctly across monitors, specify your primary display in GRUB:

```bash
sudo nano /etc/default/grub
```

Add to `GRUB_CMDLINE_LINUX_DEFAULT`:

```
video=DP-1:1920x1080@60
```

Replace `DP-1` with your monitor identifier (use `xrandr` to check). Then update GRUB:

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```
